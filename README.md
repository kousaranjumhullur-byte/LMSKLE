# 📚 Library Management System
<img width="1200" height="900" alt="collage" src="https://github.com/user-attachments/assets/2e3b0802-7684-4a95-9c30-62152c54d381" />

A modern and responsive **Library Management System** developed to simplify library operations such as managing books, users, employees, and admin activities. This project provides separate portals for **Users**, **Employees**, and **Administrators** with an attractive UI and efficient management features.

---

# 🚀 Features

## 👤 User Portal

* Browse available books
* Search books by title, author, or category
* View issued books
* Request book issue
* User dashboard interface
* Responsive design for all devices

## 👨‍💼 Employee Portal

* Manage issued and returned books
* Add student/user records
* Track due dates and fines
* Update library inventory
* Maintain borrowing history

## 🛠️ Admin Portal

* Full system management access
* Add, edit, and delete books
* Manage employees and users
* Library analytics dashboard
* Secure authentication system
* Database and server control

# ⚙️ Installation

## 1️⃣ Clone Repository

```bash
git clone https://github.com/your-username/library-management-system.git
```

## 2️⃣ Open Project Folder

```bash
cd library-management-system
```

## 3️⃣ Install Dependencies

```bash
npm install
```

## 4️⃣ Start Development Server

```bash
npm run dev
```

---

# ▶️ Run Backend Server

```bash
npm run server
```
